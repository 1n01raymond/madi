# MADI brand assets

The MADI mark combines two ideas: a connected engineering assembly and the
letter **M**. Nodes and explicit edges represent source identity and engineering
semantics; the gradient moves from CAD geometry into a WebGPU viewport.

| Asset | Intended use |
|---|---|
| [`madi-hero.svg`](madi-hero.svg) | Repository, documentation, and presentation headers |
| [`madi-mark.svg`](madi-mark.svg) | Square avatars, application icons, and compact placements |

## Palette

| Token | Hex | Use |
|---|---|---|
| Midnight | `#071426` | Primary background |
| Cyan | `#38E8FF` | Geometry and source nodes |
| Blue | `#4E9CFF` | Runtime and interaction |
| Violet | `#A56BFF` | Extensibility and derived data |
| Cloud | `#F7FBFF` | Wordmark on dark surfaces |

Keep the mark's proportions and provide clear space equal to at least one node
diameter. Do not recolor individual edges in ways that imply product status or
format compatibility.
